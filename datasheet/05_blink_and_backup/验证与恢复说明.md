## 原固件备份

`original-firmware.uf2` 为修改前通过 `picotool save -a` 读取的完整 16 MB Flash 备份。UF2 每 256 字节数据带有封装，因此文件大小为 32 MB。它不是厂商示例包里的通用固件。

## 恢复修改前程序

1. 按住板子 BOOT 按钮，同时短按 RESET，再松开 BOOT，进入 BOOTSEL 下载模式。
2. 将本目录 `original-firmware.uf2` 复制到新出现的 RP2350 下载盘，或在项目根目录执行下列命令。

```powershell
.\tools\picotool\picotool\picotool.exe load -v -x .\datasheet\05_blink_and_backup\original-firmware.uf2
```

恢复会覆盖当前闪烁程序和板内文件系统，回到备份时的 Wi-Fi 扫描示例。

## 重新设置本次闪烁程序

已安装当前专用 MicroPython 固件时，在项目根目录执行（如果串口改变，请替换 COM38）：

```powershell
$env:PYTHONPATH = "$PWD\tools\python"
python -m mpremote connect COM38 fs cp .\main.py :main.py
python -m mpremote connect COM38 reset
```

若要重新刷入专用固件，进入 BOOTSEL 后使用 `03_examples/RP2350B-Plus-W/Python/WAVESHARE_RP2350B_PLUS_W.uf2`，再上传 `main.py`。
